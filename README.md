# SENIM 2 апта Интерфейс және авторизация

Бұл нұсқа сабақ 4–6 талаптарына және пайдаланушы сұраған қызметтік профильдерге арналған. PostgreSQL, Next.js, тіркелу, кіру, профиль және рөлдік бағыттау бар. Supabase SDK, бұлттық Auth, импорттау скрипттері, AI/күнделік/жазылудың серверлік логикасы және Recharts бұл пакетке кірмейді. Күнделік, AI, жазылу және әңгіме тарихының бұрынғы дизайны әрекетсіз көрініс ретінде сақталды. Бұл беттерде inert HTML атрибуты бар: енгізу, жіберу және деректі сақтау жұмыс істемейді. График SVG арқылы көрсетіледі; Recharts орнатылмайды.

## Windows жүйесінде бірінші рет қосу

Node.js 22.18 немесе жаңа нұсқа қажет. PowerShell ашып:

```powershell
cd "C:\Users\zhaad\OneDrive\Документы\ChatGPT\senim\week 2 PostgreSQL\06_code"
npm ci
npm run setup:local
npm run db:demo
npm run launch
```

Сайт: http://127.0.0.1:3003. PostgreSQL: 127.0.0.1:5434, база senim_week2. Алғашқы production құрастыру уақыт алады. Кейін өзгермеген build қайта қолданылады. Терминал ашық тұруы керек. Тоқтату: Ctrl+C. Серверді қайта қосу: npm run launch немесе START-SENIM.cmd файлын екі рет басу.

db:demo міндетті емес. Ол тек оқшауланған жергілікті базаға үш көрсетілім аккаунтын қосады. Бар аккаунттың паролін өзгертпейді.

| Рөл | Логин | Құпия сөз | Бет |
| --- | --- | --- | --- |
| Студент | student@week2.senim.local | SenimWeek2!2026 | /dashboard |
| Психолог | psychologist@week2.senim.local | SenimWeek2!2026 | /psychologist |
| Әкімші | admin@week2.senim.local | SenimWeek2!2026 | /admin |

Бұл аккаунттар жергілікті қорғауға арналған. Жария серверде осы парольдерді қолданбаңыз. Жаңа тіркелген кез келген адам автоматты student болады.

## Өз аккаунтыңа рөл беру

Алдымен сайтта тіркел. Содан кейін жоба терминалында:

```powershell
npm run db:role -- your-email@example.com psychologist
# немесе
npm run db:role -- your-email@example.com admin
```

Шығып, қайта кір. Құпия сөз тіркелгенде өзің енгізген күйінде қалады. Рөлді форма не браузер арқылы өзгертуге болмайды. Әкімші мен психологта жаңартылған басты бет және жеке профиль бар: /admin/profile және /psychologist/profile. Аты-жөні мен бөлімін сақтау жұмыс істейді; мақалалар, кездесулер және жұмыс кестесінің дизайн экрандары қосылған.

## pgAdmin арқылы ашу

1. pgAdmin іске қос. Егер өз master password-ын сұраса, pgAdmin үшін бұрын орнатқан пароліңді енгіз. Бұл сайт паролі емес.
2. Servers → Register → Server. Name: SENIM Week 2.
3. Connection: Host 127.0.0.1, Port 5434, Maintenance database senim_week2, Username senim_week2_owner.
4. Password: осы көшірменің .env.local ішіндегі POSTGRES_PASSWORD мәні. Ол setup кезінде кездейсоқ жасалады. Оны есепке не Git-ке қоспа.
5. Databases → senim_week2 → Schemas → public → Tables → profiles → View/Edit Data → All Rows.
6. auth схемасындағы users, sessions, rate_limits кестелерін де осы жолмен қарай аласың. Құпия сөздің өзі емес, хэші сақталады.

## Қалыпты әзірлеу мен тексеру

```powershell
npm run db:start
npm run dev
# production серверін алдымен Ctrl+C арқылы тоқтат
```

```powershell
npm test
npm run build
npm run launch
# басқа терминалда, сервер қосулы кезде
npm run test:integration
```

Код өзгерсе production серверін тоқтатып, npm run launch қайта орында. .next және .next-dev бөлек. Пакетке node_modules, build, .local базасы және нақты .env.local көшірілмейді. ZIP-тен ашсаң қайта npm ci және setup:local орында.

## Архитектура және қауіпсіздік

Браузер → Next.js API және Server Actions → pg Pool → PostgreSQL. Құпия сөз scrypt, сессия HttpOnly SameSite=Lax cookie, токеннің SHA-256 хэші базада. Сессия 7 күн. Кіру сұранысы email бойынша 15 минутта 15 ретпен шектеледі. Қорғалған беттер requireRole арқылы серверде тексеріледі. SQL параметрлері $1 түрінде беріледі. Профиль owner-only RLS және UPDATE бағандарының рұқсаттарымен қорғалған. Жоғары рөлді тек owner басқару скрипті береді.

Кестелер: auth.users, auth.sessions, auth.rate_limits, public.profiles және миграция журналындағы public._senim_migrations. Толық схема db/migrations/001_week2.sql ішінде. RLS тек public.profiles кестесіне қолданылады; auth кестелері шектеулі серверлік рұқсаттар арқылы қорғалады.

Нақты студент деректері бұл көшірмеге кірмейді. 3002/5433 порттарындағы негізгі SENIM-нен бөлек 3003/5434 порттары, бөлек кластер, бөлек база және senim_week2_session cookie қолданылады.

Windows емес жүйелерде PostgreSQL-ді өзің орнатып, бос senim_week2 базасы мен owner қосылымын жаса. .env.local-ға DATABASE_URL және DATABASE_ADMIN_URL қойып, npm run db:migrate және node --env-file=.env.local scripts/configure-runtime.mjs орында. Автоматты embedded db:start/setup тек Windows үшін.

Бұл оқу прототипінде email растау, парольді қалпына келтіру, MFA және клиникалық AI жоқ. Production қолдану үшін HTTPS, құпияларды басқару, backup және кеңейтілген қауіпсіздік тексеруі қажет.

## Қызметтік профильдер

Екі қызметтік кабинетте Шолу және Профиль навигациясы бар. ProfileEditor пен saveMyProfile барлық staff профильдерінде бірдей қолданылады. Рөл форма мәнінен алынбайды: сервер сессиядан анықтайды. Аты-жөні мен факультет/бөлім ғана жаңартылады. Пошта мен рөлге UPDATE рұқсаты берілмейді.

Күнделікті сақтау, AI-ге хабарлама жіберу, жазылу және хабарландыруды оқу әрекеттерінің сервер коды жоқ. Көріністер components/preview ішінде; SQL кестелері қосылмаған. Негізгі студент макеті мен навигациясы толық жобадан сақталды. Preview ішіндегі жазбалар — синтетикалық үлгі.

Кирилл жолы бар Windows папкаларында setup бар DOS қысқа жолын қолданады. Егер дискіде қысқа жол өшірілген болса, ZIP-ті C:/senim-week2 сияқты тек латын әріптері бар папкаға ашып орнатыңыз. Бар базаны өшірмеңіз.

## Психологтың қосымша дизайн экрандары

Мақалалар, кездесулер және жұмыс кестесі мәзірден ашылады. Редактор, сүзгілер, күн/уақыт таңдау және кездесу мәліметтері браузер ішінде жұмыс істейтін UI прототиптері. Бұл әрекеттер базаға жазбайды; бетті толық жаңартсаң үлгі күйіне қайтады. Әкімшіде пайдаланушылар кестесі мен материалды тексеру көрінісі бар. Толығырақ docs/STAFF_DESIGN.md.
