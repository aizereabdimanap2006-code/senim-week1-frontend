# SENIM — бірінші аптаның Frontend жобасы

Айзереге арналған бөлек бастапқы Next.js жобасы. Бұл нұсқада жоба құрылымы, TypeScript, Tailwind CSS және қарапайым бастапқы бет бар. Қазіргі толық SENIM қосымшасынан бөлек сақталады.

## Бірінші аптаның көлемі

- Next.js App Router жобасының қаңқасы.
- TypeScript strict режимі және `@/*` импорттары.
- Tailwind CSS және Dusty Rose / Burgundy / Warm Beige палитрасы.
- Қазақ тіліндегі бейімделетін бастапқы бет.
- Компоненттер, қызметтік функциялар және типтерге арналған папкалар.
- Құпия мәндері жоқ Supabase конфигурация үлгісі.

Login/Register, Supabase байланысы, AI, күнделік және қабылдауға жазылу әзірге іске асырылмаған. Кіру мен тіркелу екінші аптаға жоспарланған.

## Компьютерде ашу

Node.js 22.18 немесе одан жаңа қолдау көрсетілетін LTS нұсқасын орнатыңыз. Папканы VS Code ішінде ашып, Terminal → New Terminal таңдаңыз.

```powershell
npm ci
npm run dev
```

Терминал көрсеткен мекенжайды браузерде ашыңыз. Әдетте http://localhost:3000; ол порт бос болмаса басқа порт ұсынылады. Тоқтату: Ctrl+C.

```powershell
npm run typecheck
npm run build
```

## Папкалар құрылымы

```text
src/
  app/          Беттер, негізгі layout және жалпы стильдер
  components/   Қайта қолданылатын интерфейс компоненттері
  lib/          Қызметтік функциялар және уақытша жоба деректері
  types/        TypeScript дерек типтері
public/         Статикалық файлдар
docs/           Бірінші аптаны көрсету мен GitHub нұсқаулығы
```

Негізгі бетті өзгерту: `src/app/page.tsx`. Түстер: `src/app/globals.css`. Жоспарланған бөлімдердің мәтіні: `src/lib/project.ts`.

## Supabase жоспары

Бірінші аптада Supabase қолдану жоспарланған. Бұл бастапқы бет базаға сұрау жібермейді, сондықтан env толтырмай-ақ ашылады.

Интеграция басталған кезде `.env.example` файлын `.env.local` ретінде көшіріп, өз жобаңыздың URL және public publishable кілтін енгізіңіз. Нақты парольдер мен secret/service-role кілттерін GitHub-қа жүктемеңіз. Сервер құпияларына `NEXT_PUBLIC_` префиксін қолданбаңыз.
